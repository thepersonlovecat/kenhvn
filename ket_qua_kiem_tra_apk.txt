================================================================================
1. BẢN MOBILE: Mobile-armeabi-v7a-release.apk
   - Package Name: com.film4k.phone
   - Kiến trúc CPU: armeabi-v7a (32-bit ARM cho điện thoại / tablet)
   - Giao diện: Jetpack Compose Mobile (hỗ trợ Touch screen)
   - Launcher: android.intent.category.LAUNCHER

2. BẢN ANDROID TV (ATV): ATV-x86_64-release.apk
   - Package Name: com.film4k.tv
   - Kiến trúc CPU: x86_64 (64-bit Intel/AMD cho Android TV Box / Giả lập TV x86)
   - Giao diện: Android TV Compose (androidx.tv.material3, Leanback, điều khiển Remote/D-pad)
   - Launcher: android.intent.category.LEANBACK_LAUNCHER (hiển thị trên giao diện Android TV / Google TV)

1. TỔNG HỢP TOÀN BỘ MÁY CHỦ (SERVER / DOMAINS / PLACEHOLDERS)
================================================================================

A. MÁY CHỦ API BACKEND CHÍNH (DÙNG CHUNG CHO CẢ 2 BẢN MOBILE VÀ ATV):
--------------------------------------------------------------------------------
1. https://fiml4k.fun
   - Vai trò: Máy chủ API Backend duy nhất xử lý toàn bộ dữ liệu (Phim, Sự kiện Thể thao, Kênh TV, IPTV, Tài khoản).
   - Chuỗi nhận diện trong app: "Phiên bản 1.0.0 • Đã kết nối fiml4k.fun".

2. Cơ chế máy chủ dự phòng / Tùy chỉnh (Custom API Server):
   - Key cài đặt: "custom_base_url" (lưu trong SharedPreferences/DataStore).
   - Ứng dụng cho phép người dùng hoặc lập trình viên nhập một Server URL khác để thay thế "https://fiml4k.fun" khi domain chính bị chặn.


B. CÁC MẪU MÁY CHỦ / PLACEHOLDER CHO TÍNH NĂNG IPTV & PORTAL:
--------------------------------------------------------------------------------
1. http://server:port
   - Chuỗi placeholder / mẫu gợi ý nhập máy chủ Xtream Codes IPTV trong giao diện thêm danh sách.
2. http://portal/c/
   - Chuỗi placeholder / mẫu gợi ý nhập URL Stalker Portal IPTV.
3. http://.../playlist.m3u
   - Chuỗi placeholder / mẫu gợi ý nhập URL playlist M3U/M3U8.


C. CÁC GIAO THỨC & MÁY CHỦ GIẢI MÃ BẢN QUYỀN DRM / MEDIA:
--------------------------------------------------------------------------------
1. http://schemas.microsoft.com/DRM/2007/03/protocols/AcquireLicense

2. https://default.url & https://x
   - URL mặc định/fallback trong parser PlayReady DRM license header (<LA_URL>).
3. http://dashif.org/guidelines/...

4. https://aomedia.org/emsg/ID3 & https://developer.apple.com/streaming/emsg-id3
   - Định danh luồng siêu dữ liệu sự kiện (ID3 metadata) trong video stream HLS / DASH.

2. CƠ CHẾ SERVER & CDN LƯU TRỮ PHIM (VOD / MOVIES / SERIES)
================================================================================
1. LINK CDN / STORAGE CÓ BỊ LỘ TRONG FILE APK KHÔNG?
   -> KHÔNG. Toàn bộ link CDN / Video Storage thực tế đều được che giấu ở Backend.
      File APK không lưu bất kỳ địa chỉ CDN tĩnh (direct S3 / Google Drive / Wasabi /
      Cloudflare R2...) nào.

2. CƠ CHẾ CẤP PHÁT NGUỒN PHIM & CDN STREAMING:
   - Bước 1: Khi bấm xem một bộ phim hoặc tập phim, ứng dụng gọi:
             + Phim lẻ: GET https://fiml4k.fun/api/watch/{slug}
             + Phim bộ: GET https://fiml4k.fun/api/watch/{slug}/{ep}
   
   - Bước 2: Server https://fiml4k.fun trả về đối tượng WatchResponse với cấu trúc:
             WatchResponse(
                 movie = Movie(...),
                 episodes = [Episode(...)],
                 sources = [
                     Source(kind="hls"|"dash"|"mp4"|"other", url="...", label="1080p | VIP Server..."),
                     ...
                 ],
                 progress = Progress(...),
                 settings = Settings(...)
             )

   - Bước 3: Định tuyến CDN & Proxy Media Stream:
             + Backend trả về các URL stream trực tiếp từ CDN hoặc thông qua endpoint:
               https://fiml4k.fun/api/f/{token_hoặc_path}
             + Endpoint "/api/f/" đóng vai trò là Stream Gateway / Proxy / Signed URL Generator,
               chuyển tiếp video từ cụm máy chủ lưu trữ (Storage/CDN) tới trình phát
               ExoPlayer của app.
             + Cơ chế này giúp chống leech link, cấp link động có thời hạn (expiring token)
               và dễ dàng đổi CDN lưu trữ ngầm mà không cần cập nhật lại app APK.

3. DANH SÁCH CHI TIẾT TOÀN BỘ CÁC API ENDPOINTS
================================================================================

A. MỤC THỂ THAO TRỰC TIẾP & TRUYỀN HÌNH (SPORT / LIVE TV / EVENTS):
--------------------------------------------------------------------------------
1. GET  https://fiml4k.fun/api/tv/events
   -> Lấy danh sách các sự kiện / trận đấu thể thao trực tiếp (EventsResponse).
   
2. GET  https://fiml4k.fun/api/tv/channels
   -> Lấy danh sách toàn bộ các kênh truyền hình trực tiếp (ChannelsResponse).

3. GET  https://fiml4k.fun/api/tv/{id}/stream
   -> Lấy luồng phát stream trực tiếp cho trận đấu hoặc kênh TV (StreamResponse).
   -> Trả về URL phát dạng HLS (.m3u8) hoặc DASH (.mpd), kèm cấu hình khóa DRM (ClearKey) nếu có.

4. GET/POST https://fiml4k.fun/api/live/heartbeat
   -> Báo cáo nhịp tim / duy trì trạng thái người dùng đang xem trực tiếp (tham số: live_viewer_id).


B. MỤC IPTV (DANH SÁCH PHÁT M3U, XTREAM CODES, STALKER PORTAL):
--------------------------------------------------------------------------------
1. GET  https://fiml4k.fun/api/iptv/playlists
   -> Lấy danh sách các playlist IPTV của người dùng.

2. GET  https://fiml4k.fun/api/iptv/playlists/{id}
   -> Chi tiết một playlist IPTV.

3. POST https://fiml4k.fun/api/iptv/parse
   -> Phân tích danh sách kênh từ link/nội dung M3U hoặc M3U8 tải lên (chỉ có trên Mobile UI).

4. GET  https://fiml4k.fun/api/iptv/play
   -> Lấy thông tin phát kênh IPTV.

5. GET  https://fiml4k.fun/api/iptv/stream?url={stream_url}
   -> Phát luồng IPTV thông qua proxy máy chủ Film4k khi mạng nội bộ bị chặn hoặc cần relay.

6. POST https://fiml4k.fun/api/iptv/xtream/sync
   -> Đồng bộ danh sách kênh và VOD từ tài khoản Xtream Codes API.

7. POST https://fiml4k.fun/api/iptv/stalker/sync
   -> Đồng bộ danh sách kênh từ Stalker Portal (MAC address).


C. MỤC PHIM VÀ NỘI DUNG VOD (MOVIES, TV SHOWS, TRANG CHỦ):
--------------------------------------------------------------------------------
1. GET  https://fiml4k.fun/api/home?
   -> Lấy toàn bộ dữ liệu hiển thị trang chủ (banner nổi bật, phim mới, đề xuất...).

2. GET  https://fiml4k.fun/api/title/{slug}
   -> Lấy thông tin chi tiết của bộ phim / bộ phim truyền hình theo slug.

3. GET  https://fiml4k.fun/api/watch/{slug}
   -> Lấy luồng phát và nguồn video cho phim lẻ.

4. GET  https://fiml4k.fun/api/watch/{slug}/{ep}
   -> Lấy luồng phát và nguồn video theo từng tập của phim bộ.

5. GET  https://fiml4k.fun/api/progress
   -> Lấy và đồng bộ tiến độ thời gian đã xem video.

6. GET  https://fiml4k.fun/api/favourites
   -> Lấy danh sách phim/kênh yêu thích của tài khoản.

7. POST https://fiml4k.fun/api/favourites/toggle
   -> Thêm hoặc xóa một mục khỏi danh sách yêu thích.

8. GET  https://fiml4k.fun/api/settings
   -> Lấy các thiết lập cấu hình chung từ máy chủ.

9. GET  https://fiml4k.fun/api/view
   -> Ghi nhận lượt xem video.

10. GET https://fiml4k.fun/api/f/
    -> Cổng định tuyến Media Stream / CDN Proxy của máy chủ Film4k.


D. MỤC XÁC THỰC TÀI KHOẢN (AUTHENTICATION):
--------------------------------------------------------------------------------
1. POST https://fiml4k.fun/api/auth/device/code
   -> Tạo mã code để liên kết / đăng nhập thiết bị trên TV (Rất quan trọng cho bản ATV).

2. GET  https://fiml4k.fun/api/auth/device/poll
   -> Kiểm tra định kỳ xem người dùng đã dùng điện thoại quét mã xác nhận đăng nhập cho TV chưa.

3. GET  https://fiml4k.fun/api/auth/google?pair={code}
   -> Xác thực tài khoản thông qua Google OAuth (Bản Mobile).

4. POST https://fiml4k.fun/api/auth/signin
   -> Đăng nhập với email / mật khẩu.

5. POST https://fiml4k.fun/api/auth/signup
   -> Đăng ký tài khoản mới.

6. GET  https://fiml4k.fun/api/auth/me
   -> Lấy thông tin hồ sơ tài khoản hiện tại.

7. POST https://fiml4k.fun/api/auth/signout
   -> Đăng xuất tài khoản.

4. VỊ TRÍ VÀ CƠ CHẾ LƯU TRỮ CÁC LINK SPORT (THỂ THAO / BÓNG ĐÁ / LIVE)
================================================================================
1. LINK SPORT CÓ BỊ HARDCODE TRONG FILE APK KHÔNG?
   -> KHÔNG. Trong cả 2 file APK không chứa bất kỳ link phát tĩnh (static/hardcoded url)
      nào của các trận đấu thể thao. Điều này giúp app không bị chết link khi nguồn
      phát thay đổi hoặc bị chặn.

2. CÁC LINK SPORT ĐƯỢC LƯU TRỮ VÀ HOẠT ĐỘNG NHƯ THẾ NÀO?
   - Bước 1: Khi mở màn hình Thể Thao (Live Screen / Tab Live), ứng dụng gọi API:
             GET https://fiml4k.fun/api/tv/events
             để lấy danh sách lịch thi đấu các trận bóng đá/thể thao theo thời gian thực.
             (Dữ liệu được parse vào model com.film4k.core.LiveEvent).

   - Bước 2: Khi người dùng bấm vào một trận đấu, app điều hướng tới màn hình:
             Route: livePlay/{id}/{name}

   - Bước 3: App gửi tiếp request tới:
             GET https://fiml4k.fun/api/tv/{id}/stream
             để lấy URL phát trực tiếp (StreamResponse).
             Link nhận về hỗ trợ:
             + Luồng HLS (.m3u8)
             + Luồng DASH (.mpd)
             + Cấu hình khóa giải mã ClearKey DRM: {"keys": [{"kty":"oct", "kid":..., "k":...}]}
             + Mở xem qua ứng dụng bên ngoài (VLC: org.videolan.vlc trên Mobile).

3. ĐỐI VỚI CÁC LINK IPTV DO NGƯỜI DÙNG TỰ THÊM (M3U / M3U8 / STALKER):
   - Nếu chưa đăng nhập (Guest): Lưu trong SharedPreferences / DataStore cục bộ của máy
     với khóa: "iptv_playlists_guest".
   - Nếu đã đăng nhập: Lưu trên đám mây máy chủ và đồng bộ qua /api/iptv/playlists.
   - Khi phát có thể chọn phát trực tiếp hoặc proxy trung gian qua:
     https://fiml4k.fun/api/iptv/stream?url={URL_GỐC}
